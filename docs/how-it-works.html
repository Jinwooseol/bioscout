동작 방식

질문 하나는 검색, 초록 읽기, 인용 답변 초안, PMID 존재 확인, 문장별 지지 판정을 거쳐 나갑니다. 근거를 못 찾은 문장은 한 번 더 검색하고, 그래도 없으면 답변에서 빠집니다.

MCP 도구 구현됨

다섯 도구 모두 읽기 전용이고, 결과는 구조화된 JSON(MCP structured content)으로 돌아옵니다. 에이전트 밖에서도 Claude Code나 Claude Desktop에 붙여 바로 쓸 수 있습니다.

오류가 났을 때

외부 API가 응답하지 않으면 429와 5xx는 최대 4번까지 간격을 늘려 재시도합니다. 그래도 실패하면 스택 트레이스 대신 에이전트가 읽고 행동할 수 있는 짧은 오류를 돌려줍니다.

Source temporarily unreachable, retry later or use another tool.
Source rejected the request (HTTP 400); check the arguments.
Replay mode: no recorded response for this call.

캐시 모드

모든 외부 응답은 요청 URL과 파라미터로 만든 키로 SQLite에 저장됩니다. API 키와 이메일은 키에 들어가지 않아, 키가 바뀌어도 같은 응답을 재사용합니다.

BIOSCOUT_CACHE_MODE동작언제 쓰나
readwrite (기본)캐시에 있으면 사용, 없으면 호출하고 저장. 30일 지나면 다시 호출개발, 데모
readonly캐시만 사용, 없으면 오류. 네트워크를 전혀 쓰지 않음CI 평가 게이트, 평가 재현
off항상 호출, 저장 안 함최신 데이터 확인, 디버깅

속도 제한은 호스트별로 따로 겁니다. NCBI는 API 키가 없으면 초당 3건, 있으면 10건까지 허용하므로 각각 2.5건, 9건으로 여유를 둡니다.
