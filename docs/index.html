BioScout는 바이오메디컬 질문에 답할 때 문장마다 PubMed 논문(PMID)을 붙이고, 그 논문이 실제로 문장을 뒷받침하는지 판정한 뒤에야 답변을 보여주는 리서치 에이전트입니다.

질문: MSI-H 대장암에서 PD-1 억제제 반응률은 MSS보다 높은가?
  1. MSI-H는 DNA 불일치 복구(MMR) 결함으로 생긴다. PMID 10000002
  2. MSI-H 종양군의 객관적 반응률이 MSS군보다 높게 보고되었다. PMID 10000002
  3. 이 차이는 cfDNA 기반 MSI 검출로도 재현된다. PMID 10000001 초록은 검출 방법만 다루고 반응률은 다루지 않아 부분 지지로 표시
  4. 반응은 모든 환자에서 2년 이상 지속된다. PMID 10000003 PubMed에 없는 PMID라 재검색 후에도 근거를 못 찾아 답변에서 삭제
지지 부분 지지 근거 없음, 삭제

출력 형식을 보여주는 예시입니다. PMID와 문장은 가상이며 실제 논문을 가리키지 않습니다.

문서

  • 동작 방식

    7일 일정의 작업별 상태, 평가 수치, 빌드 로그

    설치, 테스트, Claude Code와 Claude Desktop 연결, GitHub 푸시
