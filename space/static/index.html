BioScout

BioScout answers biomedical research questions from PubMed. It searches, answers with a citation on every sentence, and checks each citation against the paper's abstract before showing it.

This page shows answers recorded from the real agent, so it runs no model and costs nothing. To ask your own question, run BioScout with your own Claude API key: github.com/Jinwooseol/bioscout
